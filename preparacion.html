  • Git para guardar versiones y trabajar con repositorios.

  • Iniciar sesión y preparar Copilot. La disponibilidad y los límites dependen de tu cuenta.
  • OpenCode queda como ampliación: descarga oficial.

Cómo empezar una práctica

Consulta el curso en GitHub Pages. Para una práctica, extrae su ZIP dentro de tu espacio de trabajo, abre la carpeta extraída en VS Code y sigue su README. Los cuadernos sirven para estudiar Python; no tienes que completarlos antes de abrir una práctica aplicada.

  • B3: Proyecto aplicado 1 · Calcula y guarda precios.
  • B4: Proyecto aplicado 2 · Organiza productos con clases.
  • B5: Proyecto aplicado 3 · Crea un informe PDF con tus datos.
  • B6: Herramientas para trabajar con tus proyectos.
  • B7: prácticas de agentes, arneses y procedimientos reutilizables.

Comprobación mínima

  1. Abre VS Code y crea o abre una carpeta de trabajo.
  2. Comprueba que Python responde con python --version en Windows o python3 --version en Ubuntu y macOS.
  3. Abre una terminal en esa carpeta y ejecuta un archivo pequeño o una celda de prueba.

Si algo falla

  • Sin Python o Git: revisa las instrucciones oficiales de tu sistema y vuelve a comprobar las versiones.
  • Sin kernel de Jupyter: selecciona el intérprete o kernel de la carpeta de trabajo y vuelve a abrir VS Code.
  • Si PowerShell bloquea un script de preparación, no cambies la política del sistema: usa las instrucciones alternativas del README de la práctica.
  • Comparte el mensaje de error y el contexto de la carpeta abierta con el docente o con tu agente.

La preparación del ordenador y la consulta de la web son pasos distintos: el paquete local no abre ni sustituye la web del curso.
