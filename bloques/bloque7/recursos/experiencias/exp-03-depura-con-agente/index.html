Depura con un agente

Objetivo: el agente NUNCA recibe un “arréglalo” a ciegas. Tú reproduces, lees la traza, formulas tu hipótesis y el agente solo ayuda a investigar.

error reproducible → leo traceback → escribo hipótesis → contexto al agente → propone investigación → autorizo → inspección → corrección pequeña → ejecución → diff → decisión

PREPARAR

Reutiliza tu misma copia de agente-real/ de EXP-02 (con la edad ya validada y su commit). No descargues nada nuevo. Comprueba que partes de un estado limpio:

git status
python -m unittest

Debes ver el árbol limpio y las pruebas en OK. Si no, ordena tu copia antes de seguir: la depuración exige un punto de partida conocido.

VER — error reproducible + traceback real

Hay un segundo fallo real y pequeño: el programa acepta nombres vacíos o con números. Repródelo con tus manos:

python app.py
Nombre: 123
Edad: 25

Si ves Participante registrado: 123 (25 años), el fallo es real. Ahora conviértelo en evidencia automática: añade TÚ esta prueba (a mano, sin agente) y ejecútala:

def test_nombre_con_numeros_debe_rechazarse(self):
    resultado = registrar_participante("123", 25)
    self.assertEqual(resultado, "Error: el nombre solo puede contener letras.")
python -m unittest -v

Lee el traceback de abajo arriba hasta la línea AssertionError: te dice qué esperaba la prueba y qué devolvió el código. Esa lectura es tuya, no del agente.

PROBAR — tu hipótesis primero, el agente después

Escribe tu hipótesis en 2 líneas ANTES de abrir el agente (ejemplo de formato, no la respuesta):

Hipótesis: creo que falla en _______ porque _______.
Lo comprobaría mirando _______.

Ahora da contexto al agente y pídele que proponga UNA investigación, no código:

Contexto: participantes.py valida la edad (0-120) pero registrar_participante
acepta "123" como nombre. Mi hipótesis: _______.
Propón cómo investigarías la causa sin modificar archivos todavía.
No escribas código.

Lee su propuesta de investigación. Autoriza con OK - investigar o corrige con NO - ajustar: …. El agente ayuda a investigar; la hipótesis y la decisión son tuyas.

MODIFICAR — corrección pequeña + verificación

Delimita y autoriza UN cambio mínimo:

QUIERO: rechazar nombre vacío o con caracteres que no sean letras con el mensaje
"Error: el nombre solo puede contener letras.".
NO QUIERO: tocar la validación de edad, añadir dependencias,
ni reescribir app.py.

Tras el cambio del agente, verifica tú en este orden:

python app.py
python -m unittest -v
git status
git diff

Casos que debes probar a mano: nombre válido (Ana, 35 → registrado) · nombre vacío (→ error) · nombre con números (123 → error). Si el agente tocó la validación de edad o añadió algo innecesario, reduce el alcance y pide que lo retire.

MINI-RETO (autonomía)

Sin pasos detallados: formula una segunda hipótesis para el caso borde “nombre con espacios” (" Ana "). Decide tú si es fallo o comportamiento aceptable, escribe el criterio y compruébalo. Trae tu decisión por escrito.

RESULTADO OBSERVABLE

Demuestras la secuencia completa:

# 1. Fallo reproducido por ti (antes): Participante registrado: 123 (25 años)
# 2. Tu hipótesis escrita (2 líneas) + traceback leído por ti
# 3. Investigación del agente autorizada por ti (OK escrito)
# 4. Después: Error: el nombre solo puede contener letras.
# 5. Pruebas en verde, diff mínimo revisado, decisión ACEPTO/MODIFICO/RECHAZO.

Conducta evaluable: explicas qué hizo el agente y qué comprobaste personalmente. Si no puedes explicar el cambio, no se integra.

COMPROBAR

python -m unittest -v
git status
git diff

Checklist de salida: ¿error reproducido a mano? ¿traceback leído de abajo arriba? ¿hipótesis escrita antes del agente? ¿investigación autorizada? ¿corrección pequeña? ¿3 casos manuales probados? ¿diff mínimo? ¿decisión justificada?

PLAN B (sin red / sin agente)

Sin agente: intercambia tu hipótesis escrita con un compañero. Cada uno revisa la hipótesis del otro contra el traceback, propone una inspección en 3 pasos y la ejecuta en local. La corrección la escribes tú a mano y la verificas con los 3 casos manuales + pruebas.

CONTINUAR
