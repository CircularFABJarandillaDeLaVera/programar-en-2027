# Practica 02 - Pedir e inspeccionar

## Mala peticion

```text
Haz todo el repositorio y mejoralo todo.
```

## Buena peticion

```text
Modifica solo `registrar_participante` en `participantes.py` para rechazar
edades menores que 0 o mayores que 120. No cambies `app.py`, las pruebas ni
añadas dependencias.
```

## Inspeccionar

Busca:

- dependencias nuevas;
- rutas absolutas;
- APIs inventadas;
- cambios fuera del archivo pedido;
- comportamiento no probado.

## Decision

Marca cada propuesta como aceptar, modificar o rechazar.
