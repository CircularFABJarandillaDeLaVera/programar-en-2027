Bloque 7 · 6 experiencias

Trabajo como developer con agentes

Llegas sabiendo trabajar dentro de un repositorio. Ahora aprenderás a usar un agente de programación sin delegarle tu criterio: dar contexto, pedir un plan, autorizar cambios pequeños, revisar lo que hace, ejecutar, comprobar el diff y decidir si aceptas, modificas o rechazas.

Proyectos: descarga cada ZIP una sola vez y reutiliza tu copia donde se indique.

Proyecto Harness (EXP-01) Proyecto Agente-Real (EXP-02→04) Proyecto LangGraph (EXP-05) Proyecto IA-Control (EXP-06)

EXP-01 · Del prompt al Harness

Prompt vago, contexto, PLAN y verificación. 60-90 min.

EXP-02 · El agente entra en un repositorio real

Contexto, PLAN, autorización, diff y decisión. 60-90 min.

EXP-03 · Depura con un agente

Hipótesis tuya, investigación del agente. 60-90 min.

EXP-04 · Refactor, pruebas y diff

Cambio mayor con revisión crítica. 60-90 min.

EXP-05 · LangGraph: Python orquesta

Estado, nodos, rutas. Sin LLM. 60-90 min.

EXP-06 · IA local bajo control

Ollama opcional, Python valida. 60-90 min.
