Datos, librerías y resultados reales

Ya sabes programar y organizar proyectos. Ahora usarás datos y librerías externas para transformar información y generar un resultado profesional: un informe PDF.

Qué aprenderás

  • Instalar las dependencias que un proyecto necesita.
  • Explorar un CSV con Pandas: filas, columnas y filtros.
  • Hacer cálculos sencillos con NumPy.
  • Seguir el flujo de datos de un proyecto aplicado.
  • Modificar el análisis y la presentación sin romper el resultado.
  • Generar un PDF con ReportLab.
  • Comprobar el código y el artefacto final.

Resultado esperado

Al terminar podrás partir de datos reales, modificar un proyecto aplicado y demostrar que el resultado generado es correcto y útil.

Tu recorrido en orden: ① Exploro → ② Construyo y compruebo

  1. ① Descargar mini-lab de datos

    30–45 min. Descárgalo, ábrelo en VS Code y explora CSV, filtros y valores ausentes.

  2. ② Descargar proyecto SAMI-Applied

    Abre el proyecto en VS Code, instala sus dependencias y genera el informe PDF.
