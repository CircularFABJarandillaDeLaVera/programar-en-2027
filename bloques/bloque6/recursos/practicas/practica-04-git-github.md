# Practica 04 - Git y GitHub

## Requisito tecnico / laguna

La ingenieria declara laguna en comandos locales detallados, remotos y autenticacion. Esta practica trabaja el flujo conceptual y operativo basico.

## Flujo

1. cambios
2. `git status`
3. `git add`
4. `git commit`
5. `git remote`
6. `git push`
7. `git pull`

## Probar

Ordena tarjetas con esos pasos y explica que hace cada uno.

## Error util

Confundir `commit` con `push`: el commit guarda version local; push sincroniza con remoto.

## Validar

Redacta un mensaje de commit claro para una mejora de la base de herramientas.
