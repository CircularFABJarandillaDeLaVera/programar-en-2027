EXP-05 · 30-45 min · Sin red (con entorno EXP-02) · Un cambio, una función

Cambia una función sin romper el proyecto

Tu primer cambio funcional real: una sola función, un borde observable y la prueba de que el resto sigue igual. Sin agentes: esta vez decides tú.

sano → definir cambio → casos ANTES → editar 1 función → casos DESPUÉS → main.py intacto

PREPARAR

Trabajas sobre tu copia personal (mi-proyecto-b6/), la misma de EXP-01. Entorno EXP-02 activo, raíz confirmada. Ejecuta el sano de referencia (tabla + alertas: 1):

python main.py

Localiza la función con búsqueda (Ctrl+Shift+F): filtrar_stock_bajo vive en src/analizador.py y se usa en main.py línea 11. Lee solo esa función (2 líneas).

VER

La función decide con stock < stock_minimo: el umbral es exclusivo. Mira los datos reales (data/datos_hardware.csv: stocks 7, 0 y 12; config.json: mínimo 3) y escribe ANTES de tocar código:

QUIERO: umbral inclusivo; stock igual al mínimo también alerta (<=).
NO QUIERO: tocar otra función, cambiar config/datos, nuevas dependencias.
ARCHIVO: src/analizador.py
FUNCIÓN: filtrar_stock_bajo(tabla, stock_minimo)
CASO ACTUAL: stock 7 con umbral 7 → NO alerta (Ryzen 5 se escapa).
CASO NUEVO ESPERADO: stock 7 con umbral 7 → SÍ alerta; resto idéntico.

En tres palabras: QUIERO es tu objetivo, ARCHIVO/FUNCIÓN es tu contexto, y los casos ANTES/DESPUÉS más main.py son tu verificación.

PROBAR (casos ANTES, con datos reales)

Registra la salida actual con estas sondas (no adivines, ejecuta):

python -c "from src.analizador import cargar_datos, filtrar_stock_bajo; t=cargar_datos('data/datos_hardware.csv'); print('umbral 3:',sorted(filtrar_stock_bajo(t,3)['id'])); print('umbral 7:',sorted(filtrar_stock_bajo(t,7)['id']))"

Deberías ver umbral 3: ['RAM-02'] y umbral 7: ['RAM-02']: tres casos en dos líneas (normal RAM-02/3, borde Ryzen/7, no afectado SSD-12). Guárdalos: son tu ANTES.

MODIFICAR (una línea, una función)

Cambia solo el operador en src/analizador.py:

# ANTES:
return tabla[tabla["stock"] < stock_minimo]
# DESPUÉS:
return tabla[tabla["stock"] <= stock_minimo]

Repite las mismas sondas y compara:

# DESPUÉS esperado:
umbral 3: ['RAM-02']            (igual: lo anterior sigue funcionando)
umbral 7: ['CPU-01', 'RAM-02']  (borde: Ryzen 5 ahora alerta)

Cierra ejecutando el proyecto completo:

python main.py

La tabla es idéntica y el informe sigue en alertas: 1 (la config usa mínimo 3): el proyecto funciona y tu cambio solo se nota donde lo definiste.

Define cambio + límite, comprueba ANTES (precio == umbral → hoy PRECIO_NORMAL), modifica, comprueba DESPUÉS (borde + un caso por encima + uno por debajo). Solo esa función.

RESULTADO OBSERVABLE

ANTES:   umbral 3 → [RAM-02] · umbral 7 → [RAM-02]
CAMBIO:  1 línea en filtrar_stock_bajo (< → <=)
DESPUÉS: umbral 3 → [RAM-02] · umbral 7 → [CPU-01, RAM-02]
PROYECTO: python main.py idéntico (alertas: 1)

Y en voz alta: “cambié ___ en esta función para conseguir ___. No toqué ___. Lo comprobé con estos casos”.
