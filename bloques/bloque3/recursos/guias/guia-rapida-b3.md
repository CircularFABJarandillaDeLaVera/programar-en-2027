# Guia rapida - Bloque 3

## Funcion
`def nombre(parametro):`

## Retorno
`return valor`

## Print
Muestra en consola. No sustituye a `return`.

## Parametros por defecto
Los opcionales van al final.

## Scope
Local dentro de la funcion. Exterior fuera.

## Excepciones
EJECUTAR -> OBSERVAR -> INTERPRETAR -> CORREGIR -> VOLVER A EJECUTAR

## Archivos
Usa `with open(..., encoding="utf-8")`.

## Persistencia
TXT para texto. JSON para diccionarios. CSV para tablas.

## Modulos
Separa responsabilidades. Importa solo lo necesario.

## Proyecto aplicado 1 · Calcula y guarda precios
`persistencia.py` guarda y carga.  
`analizador.py` calcula y valida.  
`main.py` coordina.
