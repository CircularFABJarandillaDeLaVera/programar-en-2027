Programar en 2027

Preparación sencilla del ordenador · Windows
Circular FAB Jarandilla de la Vera · 29/10/2026

1. Prepara el ordenador

  1. Descarga el paquete de preparación para Windows y pulsa Extraer todo.
  2. Cierra VS Code. En la carpeta extraída abre Preparar_curso.cmd con doble clic. Conserva preparar.py junto al CMD.
  3. Pulsa una tecla para empezar y acepta los avisos de instalación que correspondan. Necesitas Internet y no debes cerrar la ventana mientras se prepara el equipo.
  4. Al terminar debe aparecer PREPARACION COMPLETADA. El paquete prepara Python, VS Code, Git, extensiones y un espacio de trabajo local; no es un lanzador de la web.

No hace falta abrirlo como administrador. El paquete no cambia la política de ejecución de PowerShell ni crea cuentas o suscripciones.

2. Abre el espacio de trabajo local

Dentro de Programar2027, abre Abrir_curso.cmd para abrir VS Code en castellano. Inicia sesión en GitHub/Copilot desde VS Code solo si vas a utilizar esa herramienta.

El curso se consulta en GitHub Pages:

https://circularfabjarandilladelavera.github.io/programar-en-2027/inicio.html

3. Prueba Python y el cuaderno

  • Abre hola.py, ejecútalo en la terminal y escribe tu nombre.
  • Abre prueba.ipynb y elige el kernel Python (Programar 2027).
  • Ejecuta la celda: debe mostrar «¡El cuaderno funciona!».

4. Elige una práctica

Extrae cada ZIP dentro de Programar2027, abre la carpeta extraída en VS Code y sigue su README. Los cuadernos sirven para estudiar Python; no tienes que completarlos antes de abrir una práctica aplicada.

  • B3: Proyecto aplicado 1 · Calcula y guarda precios.
  • B4: Proyecto aplicado 2 · Organiza productos con clases.
  • B5: Proyecto aplicado 3 · Crea un informe PDF con tus datos.
  • B6: Herramientas para trabajar con tus proyectos.
  • B7: prácticas de agentes, arneses y procedimientos reutilizables.

5. Si algo falla

  • Sin WinGet: actualiza «Instalador de aplicación» desde Microsoft Store o pide ayuda al responsable del equipo.
  • Sin Python o Git: reinicia Windows y repite Preparar_curso.cmd.
  • Sin kernel: cierra y vuelve a abrir VS Code con Abrir_curso.cmd.
  • Comparte el mensaje de error y preparacion.log. No ejecutes preparar.py con doble clic.

Fuentes: WinGet, VS Code, Git y kernels de Jupyter.
