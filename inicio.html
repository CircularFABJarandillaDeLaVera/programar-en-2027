Descargar guía de preparación

Guía y descargas oficiales

  • Crear cuenta de GitHub: confirma tu correo.
  • Descargar Python para Windows.
  • Descargar Visual Studio Code.
  • Descargar Git para guardar versiones y trabajar con repositorios.
  • Extensiones de VS Code: Python, Español, Jupyter y GitHub Copilot Chat.
  • Iniciar sesión y preparar Copilot. La disponibilidad y los límites dependen de tu cuenta.
  • Opcional: descargar OpenCode, siguiendo el anexo de la guía.

¿Te has atascado?

Sube la guía a un GPT y pídele que te acompañe paso a paso. Indica en qué apartado estás y copia el mensaje de error o añade una captura. También puedes pedir una tutoría al docente para resolverlo juntos.

Los cuadernos son opcionales. Puedes comenzar con las prácticas del curso.
