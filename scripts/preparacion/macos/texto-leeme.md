Empieza aquí — macOS

1. Extrae el ZIP completo y conserva juntos los cuatro archivos.
2. Prueba a abrir Preparar_curso.command desde Finder. Si no se abre, usa Terminal
   en la carpeta extraída y escribe: bash Preparar_curso.command
3. Lee cada paso, confirma los cambios que quieras realizar y espera al resumen final.

El comando con bash funciona aunque se pierda el permiso de ejecución al extraer
el ZIP. Para abrir el archivo directamente desde Terminal puedes usar:
chmod +x Preparar_curso.command
./Preparar_curso.command
Si macOS muestra un aviso de seguridad, verifica que el ZIP procede del curso.
Puedes usar clic secundario > Abrir para revisar el aviso o seguir la guía manual.
No desactives las protecciones del sistema. La ventana de Terminal espera a que
pulses Intro al terminar si se ha abierto de forma interactiva.

QUÉ PREPARA

Comprueba Python 3, pip, Git, Visual Studio Code y la extensión Python de Microsoft.
Si falta Python, muestra el enlace oficial de macOS sin necesitar Python para ello.
Si falta Git, propone las herramientas de línea de comandos de Apple. Para VS Code,
indica cómo instalar la aplicación oficial para Apple Silicon o Intel. Crea
~/programar-2027/primera-practica con hola.py y un entorno .venv; conserva los
archivos existentes al repetirlo. No crea cuentas ni inicia sesión por ti.
Necesitas Internet para descargas e instalaciones.

SI ALGO QUEDA PENDIENTE

Lee el resumen, completa el paso indicado y vuelve a ejecutar el lanzador.
En equipos administrados, pide ayuda a la persona responsable antes de instalar.
