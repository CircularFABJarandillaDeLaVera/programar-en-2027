Empieza aquí — Windows

1. Extrae el ZIP completo con «Extraer todo».
2. Cierra VS Code y abre Preparar_curso.cmd con doble clic en la carpeta extraída.
3. Lee los mensajes, confirma las instalaciones y espera al resumen final.

Conserva preparar.py junto al archivo CMD: trabajan juntos. Necesitas Internet.
No abras el CMD como administrador; el instalador de Git puede pedir permisos solo
cuando los necesite. Si falta WinGet, consulta «Si algo falla» más abajo.

AL TERMINAR

Se crea la carpeta Programar2027 en tu carpeta personal de Windows. Guarda allí
las prácticas extraídas de sus ZIP. Abre Abrir_curso.cmd en esa carpeta para
iniciar el espacio de trabajo local de VS Code. La web del curso se consulta en:
https://circularfabjarandilladelavera.github.io/programar-en-2027/inicio.html
El paquete prepara el ordenador y el editor; no abre ni sustituye la web.

En VS Code, abre hola.py, ejecuta el archivo en la terminal y escribe tu nombre.
Abre también prueba.ipynb y selecciona Python (Programar 2027) como kernel.
Si no aparece, selecciona el entorno .venv de la carpeta Programar2027.

QUÉ PREPARA

- Python 3.13, Visual Studio Code y Git si no están instalados.
- Extensiones de Python, castellano, Jupyter y GitHub Copilot Chat.
- Un entorno .venv con ipykernel, un espacio de trabajo, hola.py y prueba.ipynb.
- Un registro de incidencias en Programar2027\preparacion.log.

La cuenta de GitHub, la confirmación del correo y el inicio de sesión en Copilot
se hacen por separado. El preparador no crea cuentas, introduce credenciales ni
contrata suscripciones. La disponibilidad de Copilot depende de tu cuenta.

SI ALGO FALLA

- Si no existe WinGet, actualiza «Instalador de aplicación» desde Microsoft Store.
  En un equipo gestionado, pide ayuda a la persona responsable.
- Si no se encuentra Python o Git tras instalar, reinicia Windows y repite el CMD.
- Si falla la red o una extensión, comprueba Internet y repite el CMD.
- Si no aparece el kernel, cierra VS Code y vuelve a abrirlo con Abrir_curso.cmd.
- Comparte el error y preparacion.log con el docente. Los errores anteriores al
  arranque de Python aparecen solo en la ventana CMD.

Puedes repetir el preparador: conserva los ejercicios y la configuración
existentes y vuelve a comprobar los componentes.
