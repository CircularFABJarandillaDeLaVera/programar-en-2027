Empieza aquí — Ubuntu

1. Extrae el ZIP completo en una carpeta.
2. Abre una terminal en esa carpeta y escribe: bash Preparar_curso.sh
3. Lee cada paso, confirma los cambios que quieras realizar y espera al resumen final.

El archivo .sh no se inicia siempre con doble clic en Ubuntu. El comando anterior
funciona aunque se pierda el permiso de ejecución al extraer el ZIP. Conserva
preparar.py en la misma carpeta. La ventana de Terminal espera a que pulses Intro
al terminar si se ha abierto de forma interactiva.

QUÉ PREPARA

Comprueba Python 3, pip, Git, Visual Studio Code y la extensión Python de Microsoft.
Si falta Python, el lanzador ofrece instalarlo mediante apt antes de usar Python.
Para VS Code, utiliza el paquete .deb descargado desde la página oficial y pide
confirmación antes de instalarlo. Crea ~/programar-2027/primera-practica con
hola.py y un entorno .venv; conserva los archivos existentes al repetirlo.
Solo usa sudo en las instalaciones apt que lo requieran. No crea cuentas ni inicia
sesión por ti. Necesitas Internet para descargas e instalaciones.

SI ALGO QUEDA PENDIENTE

Lee el resumen, completa el paso indicado y vuelve a ejecutar el mismo comando.
Si el archivo descargado no se inicia por permisos, abre Terminal en la carpeta
extraída y usa: bash Preparar_curso.sh
Para hacerlo ejecutable desde Terminal: chmod +x Preparar_curso.sh
En equipos administrados, pide ayuda a la persona responsable antes de instalar.
