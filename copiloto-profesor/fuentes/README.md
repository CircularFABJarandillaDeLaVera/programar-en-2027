# Fuentes Curadas de Ingeniería del Conocimiento

Esta carpeta contiene una selección rigurosa de los documentos maestros de **Ingeniería del Conocimiento** correspondientes al itinerario *Programar con Python en 2027*.

---

## Criterio de Selección y Saneamiento

Para optimizar la ventana de contexto y la precisión del asistente:
1. **Exclusión de archivos de interfaz:** No se incluyen archivos HTML, CSS, JavaScript de interfaz ni recursos gráficos del portal web.
2. **Saneamiento de codificación:** Todos los archivos han sido verificados y consolidados en codificación **UTF-8 estricta** (0% mojibake).
3. **Alto valor curricular:** Conservan las tablas de decisión, especificaciones técnicas de APIs y desgloses de bajo nivel que respaldan los documentos sintéticos `01` a `07`.

Nota de precedencia: estas fuentes curadas pueden prevalecer sobre la ingeniería global viva externa cuando aquella conserve mojibake, referencias de año obsoleto, PyPDF como laguna obsoleta, restos conversacionales o contradicciones con el estado validado del curso.
