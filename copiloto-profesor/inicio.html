Adapta tu profesor particular

Un asistente educativo necesita instrucciones, contexto, fuentes, límites, tareas y una forma de reconocer lo que no sabe. El README del pack explica qué aporta cada archivo y cuándo consultarlo.

  1. Define la función: qué curso impartes y a quién ayudas.
  2. Da instrucciones: rol, objetivos, tono, límites y cómo reconocer dudas.
  3. Selecciona conocimiento real: temario, prácticas y fuentes organizadas.
  4. Delimita las tareas: puede proponer y explicar; el docente revisa los cambios y decide.
  5. Añade ejemplos: buenas respuestas, dudas y errores habituales.
  6. Valida: prueba una pregunta documentada, otra fuera del temario, una ambigua, una actividad y una petición imposible.
  7. Mejora con el uso: registra errores, apoyos útiles y lagunas; revisa las fuentes afectadas.

Adapta una copia para otra especialidad. No basta con cambiar el nombre: sustituye fuentes, ejemplos, nivel y límites.

Al crear materiales: contexto → objetivo y límites → plan → aprobación → cambio → validación → guardado. Una autorización explícita ya concedida no necesita repetirse.

Conserva siempre la distinción [SEGÚN EL CURSO] / [EXPLICACIÓN COMPLEMENTARIA]. Si falta evidencia, el agente debe decirlo.

Si la herramienta puede crear archivos, el profesor particular puede preparar un ZIP descargable de un proyecto inicial. Si no puede, entrega los contenidos y los pasos para crearlo sin afirmar que existe un archivo.

Preguntas de ejemplo

  • “No entiendo los bucles. Dame una pista sin darme la solución.”
  • “Voy a impartir el Bloque 5 mañana. ¿Qué tengo que preparar y qué puede fallar?”
  • “Explícame las comprensiones como si tuviera 12 años.”
  • “Dame un Plan B si esta práctica falla.”
  • “¿Esto forma parte del curso o es una explicación complementaria?”
  • “Solo tengo 60 minutos. ¿Qué priorizo?”
  • “Quiero hacer un juego de ajedrez. Ayúdame a preparar un kit inicial para trabajar con un agente en VS Code.”
