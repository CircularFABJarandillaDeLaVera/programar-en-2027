UNA IA QUE RESPONDE CON ESTRUCTURA

DESCARGAR PRÁCTICA

La Exp 23 demostró que el problema no era solo la forma del texto, sino la falta de validación semántica del contenido.

Punto de partida pedagógico

En la experiencia anterior vimos esta secuencia:

LangGraph decide
Ollama explica
Python valida

Durante las pruebas reales apareció una evidencia importante:

  • si pedías JSON solo por prompt, `llama3.2:1b` podía devolver texto que no era JSON;
  • al usar la API real con `format` y JSON Schema, el modelo sí devolvió un JSON estructurado;
  • pero volvió a inventar afirmaciones no presentes en los datos, como microorganismos, evaporación o condiciones óptimas.

Eso enseña algo clave:

JSON válido ≠ contenido válido

Regla de responsabilidades

LangGraph -> DECIDE
Ollama -> EXPLICA
JSON Schema -> ESTRUCTURA
Python -> VALIDA

El LLM no puede cambiar la decisión, establecer reglas de negocio ni inventar cifras o causas.

JSON Schema real

{
  "type": "object",
  "properties": {
    "explicacion": {"type": "string"},
    "accion": {"type": "string"}
  },
  "required": ["explicacion", "accion"],
  "additionalProperties": false
}

Se usa con la API de Ollama local:

POST http://localhost:11434/api/generate

Con variables:

OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=llama3.2:1b

Importante: no confundamos estructura con verdad

No se debe decir que:

“Ahora Ollama siempre dice la verdad porque usamos JSON Schema”

La realidad es otra: el esquema corrige la estructura; Python sigue siendo la capa que valida si el contenido es legítimo.

Validador semántico

Se reutiliza el guardrail didáctico de la experiencia 23 y se mejora:

  • existen `explicacion` y `accion`;
  • son strings;
  • no aparecen números distintos de los datos permitidos;
  • no cambia la decisión;
  • la acción corresponde a la decisión;
  • detecta términos prohibidos como microorganismos, evaporación, gases tóxicos, contaminación o toxicidad;
  • rechaza causas y consecuencias externas inventadas.

Esta blacklist es didáctica y no es una garantía universal contra alucinaciones.

Fallback determinista

EXPLICACIÓN
El dispositivo compostera-cf-01 registra 48 °C y 60 % de humedad. La decisión del sistema es REVISAR_TEMPERATURA.

ACCIÓN
Una persona debe revisar la temperatura del dispositivo.

Modo sin IA

python respuesta_estructurada.py --demo --sin-ia

Este modo demuestra que el sistema funciona sin consultar a un LLM y que la capacidad operativa no depende del modelo.

Mini-reto
