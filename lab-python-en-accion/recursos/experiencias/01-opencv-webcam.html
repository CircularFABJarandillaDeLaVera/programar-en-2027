Webcam interactiva con OpenCV

Descargar script .py

Objetivo: abrir la webcam desde Python, cambiar el modo de imagen en tiempo real y guardar una captura.

VER

Una ventana de video cambia entre normal, gris, desenfoque y bordes.

PROBAR

Ejecuta el script y pulsa las teclas con la ventana activa.

MODIFICAR

Cambia el kernel de blur, los umbrales de Canny o el nombre de captura.

MINI-RETO

Haz que la captura incluya el modo activo en el nombre.

Que vas a conseguir

Una webcam interactiva con cuatro modos y una imagen guardada como `captura_opencv.png` al pulsar `S`.

1 NORMAL 2 GRIS 3 BLUR 4 BORDES S CAPTURA Q SALIR

Instalacion y ejecucion

pip install opencv-python
python ../scripts/webcam_gris.py

La ventana de OpenCV debe estar activa para que `waitKey()` detecte las teclas.

Codigo relevante

if modo == "gris":
    mostrado = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
elif modo == "blur":
    mostrado = cv2.GaussianBlur(frame, (15, 15), 0)
elif modo == "bordes":
    gris = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    suave = cv2.GaussianBlur(gris, (5, 5), 0)
    mostrado = cv2.Canny(suave, 100, 200)

Resultado esperado y Plan B

Resultado: video interactivo en tiempo real y captura local si pulsas `S`. Si la webcam no abre, revisa permisos, cierra otras apps que usen la camara o prueba `VideoCapture(1)`.
