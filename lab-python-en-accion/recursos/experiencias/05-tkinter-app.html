Objetivo: crear una pequena ventana con campo de texto, boton y resultado.

VER

Una ventana local saluda al usuario.

PROBAR

Ejecuta el script y escribe un nombre.

MODIFICAR

Cambia el texto del boton y el mensaje final.

MINI-RETO

Anade un segundo campo para la edad.

Que vas a conseguir

Una app local con `Entry`, `Button`, `StringVar` y `Label`, mantenida viva por `mainloop()`.

Instalacion y ejecucion

python ../scripts/mi_app_tkinter.py

Tkinter suele venir con Python.

Codigo relevante

def saludar():
    nombre = entrada.get()
    mensaje.set(f"Hola, {nombre}. Tu codigo ya tiene ventana.")

tk.Button(root, text="Saludar", command=saludar).pack()
tk.Label(root, textvariable=mensaje).pack()
root.mainloop()

Resultado esperado y Plan B

Resultado: una app local que saluda al usuario. Si Tcl/Tk no esta disponible o el equipo no puede abrir ventanas, adapta la funcion a consola con `input()` y `print()`.
