Modifica una foto con Python

Descargar script .py

Objetivo: abrir una imagen neutra de prueba, transformarla y guardar una nueva imagen.

VER

Python abre `foto_original.ppm` y prepara una copia editada.

PROBAR

Ejecuta el script y abre `foto_editada.jpg`.

MODIFICAR

Cambia tamano, angulo de rotacion o recorte.

MINI-RETO

Genera dos salidas: una en gris y otra recortada.

Que vas a conseguir

Una nueva imagen procesada sin alterar la imagen neutra original del Lab.

Instalacion y ejecucion

pip install Pillow
python ../scripts/editar_foto.py

El script usa `../assets/foto_original.ppm`, no el logotipo corporativo.

Codigo relevante

imagen = Image.open(entrada)
pequena = imagen.resize((400, 300))
recortada = pequena.crop((30, 20, 370, 280))
gris = recortada.rotate(8).convert("L")
gris.filter(ImageFilter.BLUR).save(salida)

Resultado esperado y Plan B

Resultado: `foto_editada.jpg`. Si no encuentra la imagen, comprueba que existe `lab-python-en-accion/recursos/assets/foto_original.ppm`.
