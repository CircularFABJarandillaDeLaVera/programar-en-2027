Ordena una carpeta automaticamente

Descargar script .py

Objetivo: organizar archivos falsos dentro de una carpeta segura del Lab.

VER

Una carpeta de pruebas queda clasificada por tipo de archivo.

PROBAR

Ejecuta el script con Python estandar, sin instalar librerias.

MODIFICAR

Anade otra extension al diccionario de destinos.

MINI-RETO

Imprime cada movimiento como `origen -> destino`.

Que vas a conseguir

`lab_archivos_prueba` clasificada en `PDFs`, `Imagenes`, `Codigo`, `Textos` y `Otros`.

Instalacion y ejecucion

python ../scripts/organizar_carpeta_segura.py

El script trabaja exclusivamente sobre `lab-python-en-accion/recursos/lab_archivos_prueba/`.

Codigo relevante

base_dir = Path(__file__).resolve().parents[1]
carpeta = base_dir / "lab_archivos_prueba"
nombre_destino = destinos.get(ruta.suffix.lower(), "Otros")
shutil.move(str(ruta), str(destino))

Resultado esperado y Plan B

Resultado: archivos falsos organizados. Si hay dudas, cambia `MOVER_ARCHIVOS = True` por `False` para simular. No uses carpetas reales externas.
