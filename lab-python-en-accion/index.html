Recorrido práctico

Construye y conecta tus proyectos

Convierte un programa en una aplicación que guarda datos, conecta herramientas y puede utilizarse desde distintos dispositivos. Recorre seis etapas para identificar la pieza que necesitas, conectarla y comprobarla.

Continuidad real: el control horario sirve como hilo de ejemplo desde EXP 11, pero cada descarga es una carpeta independiente. Abre la carpeta que descomprimas y sigue su README; no se presupone que una copia admita automáticamente los archivos de otra.

ETAPA 1

Trabaja con control

Aprende a colaborar con un agente de programación manteniendo el control del proyecto.

Qué vas a conseguir

Controlar un cambio con ayuda de un agente y conservar una versión revisada.

Con qué trabajarás

Extrae agentes-programacion.zip, abre agente-programacion/ y usa su proyecto, diff y pruebas.

Cómo comprobarlo

Ejecuta python app.py y python -m unittest -v; revisa el diff antes de guardar.

30-45 min

ETAPA 2

Haz que tus programas se comuniquen

Convierte tu código en una API y aprende a ejecutarla de forma reproducible.

Qué vas a conseguir

Exponer un programa como API y ejecutarlo de forma reproducible.

Con qué trabajarás

Extrae cada ZIP en su propia carpeta. FastAPI usa su entorno virtual y requirements.txt; Docker añade imagen, contenedor y puertos.

Cómo comprobarlo

Ejecuta uvicorn main:app --reload, revisa Swagger y test_api.py. Docker requiere Docker Desktop.
