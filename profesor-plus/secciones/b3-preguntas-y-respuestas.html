Bloque 3 · Preguntas y respuestas

Predicción, excepciones y modularidad.

Preguntas útiles

  • Que devuelve esta funcion?
  • Que imprime y que guarda?
  • Cual es el parametro y cual es el argumento?
  • Que variable es local?
  • Que excepcion concreta esperamos?
  • Que formato conviene: TXT, JSON o CSV?
  • Que archivo debe tener esta responsabilidad?

Respuestas esperadas

  • return devuelve datos reutilizables.
  • print() solo muestra en consola.
  • Un parametro esta en la firma; un argumento aparece en la llamada.
  • global solo se usa si la funcion debe modificar una variable exterior.
  • with open() evita gestionar el cierre manual del archivo.
  • main.py coordina; los modulos auxiliares calculan o guardan.
