Bloque 4 · Apoyos y plan B

Bloqueados, rápidos y plan B.

Alumnos bloqueados

  • Dar una plantilla con class Producto, __init__ y un metodo vacio.
  • Pedir que solo cambien un atributo y ejecuten.
  • Reducir la tarea a una instancia y una llamada de metodo.
  • Usar tarjetas "clase", "objeto", "atributo", "metodo" para ordenar conceptos.

Alumnos rápidos

  • Anadir validacion de precio en un setter simple.
  • Crear una subclase adicional sin introducir bibliotecas externas.
  • Hacer una lista mixta de productos y llamar al mismo metodo.
  • Separar responsabilidades entre analizador.py, persistencia.py y main.py.

Actividad de polimorfismo

  1. Cada equipo crea una subclase distinta de Producto.
  2. Todas deben tener un metodo resumen().
  3. Se juntan en una misma lista.
  4. El programa recorre la lista sin preguntar de que clase es cada objeto.

Plan B sin Internet

  • Usar editor local o cuaderno ya descargado.
  • Copiar el codigo minimo en un archivo .py.
  • Ejecutar desde terminal o entorno local disponible.
  • Si no hay ejecucion, hacer prediccion y traza manual de atributos.

Cierre

La pregunta final no es "que es POO", sino "que problema de organizacion resuelve aqui".
