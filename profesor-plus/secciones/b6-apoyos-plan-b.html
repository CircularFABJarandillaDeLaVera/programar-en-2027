Bloque 6 · Apoyos y plan B

Bloqueos técnicos y alternativas.

Si falla Python

  • Trabajar con pseudoejecucion de scripts.
  • Identificar donde iria print.
  • Leer tracebacks simulados.

Si falla VS Code

  • Usar editor simple y terminal externa.
  • Mantener la estructura de carpetas.

Si falla venv

  • No instalar paquetes a ciegas.
  • Documentar la incidencia como requisito tecnico.
  • Continuar con estructura, requirements y diagnostico conceptual.

Si falla GitHub

  • Trabajar solo Git local conceptual.
  • Ordenar status, add, commit, remote, push y pull.

Si falla la extension IA

  • Simular una sugerencia escrita.
  • Revisarla con el protocolo leer, probar, validar.
