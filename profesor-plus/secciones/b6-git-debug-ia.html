Bloque 6 · Git, debug e IA

Versionado, trazas y asistencia controlada.

Git local

Flujo que debe entenderse:

cambios -> git status -> git add -> git commit

GitHub

Mapa conceptual:

repositorio local -> remote -> push/pull

Autenticacion y remotos detallados quedan como laguna tecnica.

Traceback

Leer:

  1. ultima linea significativa;
  2. tipo de error;
  3. archivo;
  4. linea;
  5. dato que lo provoca.

Breakpoint

Pedir al alumno que escriba una hipotesis antes de pausar.

IA controlada

Usos permitidos: explicar codigo, cambio pequeno, funcion sencilla, localizar error o revisar propuesta.

Regla: no aceptar nada sin leer, probar y validar.
