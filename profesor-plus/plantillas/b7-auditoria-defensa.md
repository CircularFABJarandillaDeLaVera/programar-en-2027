# B7 Auditoria y defensa

## Auditar codigo generado

Revisar:

- dependencias nuevas;
- APIs inventadas;
- rutas absolutas;
- cambios fuera de alcance;
- funciones que el alumno no entiende;
- ausencia de prueba.

## Defensa del proyecto final heredado

El alumno debe explicar:

- entradas;
- salidas;
- flujo;
- decisiones;
- errores localizados;
- ayuda IA usada;
- validacion personal.

No necesita recitar cada linea.
