# B7 Planes B

## Si no hay acceso a IA

- Usar una propuesta escrita por el profesor.
- Auditarla como si viniera de un asistente.
- Decidir aceptar, modificar o rechazar.

## Si la IA alucina

- Pedir fuente o explicacion.
- Verificar si la API existe en el proyecto.
- Rechazar dependencias no autorizadas.

## Si el alumno delega demasiado

- Reducir la tarea a una funcion.
- Pedir explicacion en voz alta.
- Exigir prueba con entrada y salida esperada.
